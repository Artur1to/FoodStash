# FoodStash

FoodStash — сайт рецептов, разработанный в рамках студенческой курсовой работы. Он помогает выбрать, что приготовить из продуктов, которые уже есть дома. Пользователь вводит список ингредиентов, а сайт показывает подходящие рецепты, отмечает недостающие продукты и сортирует блюда по степени совпадения.

[Открыть демоверсию FoodStash](https://foodstash-recipes.vercel.app/)

## Возможности

- **Поиск рецептов.** Поиск по ингредиентам и названию, фильтры по категории, сложности и времени приготовления. Можно показать только блюда, для которых есть все продукты.
- **Карточка блюда.** Фото, пошаговое приготовление, состав и пищевая ценность. При изменении числа порций количество ингредиентов и указанные КБЖУ пересчитываются.
- **Публикация и обсуждение.** Авторы добавляют и редактируют свои рецепты. Участники могут ставить оценки и лайки, оставлять комментарии и сохранять блюда в избранное.
- **Профили и подписки.** У каждого участника есть профиль с рецептами и достижениями. Новые публикации авторов, на которых он подписан, появляются в личной ленте.

## Технологии

Сайт разработан на **Python и Django**. Интерфейс использует шаблоны Django, CSS и JavaScript. AJAX обновляет результаты поиска, фильтры и сортировку комментариев без полной перезагрузки страницы.

Демоверсия размещена на **Vercel**. Данные хранятся в **PostgreSQL на Neon**, а фотографии — в **Vercel Blob**. Для локальной разработки используется **SQLite**.
